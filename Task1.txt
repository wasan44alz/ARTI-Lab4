Task 1 - Unification

27 ?- house=house.
true.

Both atoms are identical, so they unify.

28 ?- house=abc.
false.

house and abc are different atoms, so they cannot unify.

29 ?- edge(a,b)=edge(C,b).
C = a.

C is instantiated to a, making both structures identical.


30 ?- edge(a,d) = edge(C,B).
C = a,
B = d.

C is instantiated to a and B is instantiated to d.

31 ?- edge(C,B) = edge(a,d).
C = a,
B = d.

The variables can take the values needed to make both structures identical.

32 ?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).

A is instantiated to a and B is instantiated to the structure f(g,h).

33 ?- edge(A,A) = edge(b,c).
false.

A would have to be both b and c, which is impossible.

34 ?- edge(A,A) = edge(b,b).
A = b.

Both occurrences of A can take the same value b.

35 ?- A = B, B = f.
A = B, B = f.

A and B are linked, and B is then instantiated to f.

36 ?- A = B, B = f, A = e.
false.

A and B become f, so A cannot also be e.
